# Zakład Mechaniki Pojazdowej – Tadeusz Sielawa (Białystok)

Strona internetowa warsztatu samochodowego **Zakład Mechaniki Pojazdowej Tadeusz Sielawa** zlokalizowanego w Białymstoku przy **ul. Tęczowej 2 (15-365 Białystok)**. Warsztat działa od **ponad 20 lat**, oferuje **korzystne ceny** i specjalizuje się w naprawie automatycznych skrzyń biegów (**DSG, tiptronic, S-tronic, MPS6**), wymianie **sprzęgieł suchych i mokrych**, **dynamicznej wymianie oleju** w automatycznej skrzyni biegów oraz pełnym zakresie mechaniki pojazdowej (sprzęgła, rozrządy, hamulce, zawieszenie, skrzynie manualne).

## Jak uaktywnić (uruchomić) stronę na GitHub Pages?
1. Wejdź w swoje repozytorium na **github.com** i upewnij się, że w głównym katalogu znajdują się pliki `index.html`, `oferta.html`, `kontakt.html`, `style.css`, `README.md` oraz folder `img/`.
2. Kliknij zakładkę **Settings** na górnym pasku repozytorium.
3. W menu po lewej stronie wybierz **Pages**.
4. W sekcji **Build and deployment → Branch** wybierz gałąź **main** oraz folder **/ (root)**, a następnie kliknij **Save**.
5. Odczekaj około 1–2 minuty, aż GitHub zbuduje i opublikuje witrynę (postęp widać w zakładce **Actions** lub w sekcji **Deployments** na stronie głównej repozytorium).
6. Otwórz powyższy link do strony w przeglądarce (w razie potrzeby odśwież stronę skrótem **Ctrl + F5**, aby pobrać najnowszą wersję).

## Struktura projektu
* `index.html` – Strona główna z animacjami przewijania, opisem warsztatu (ponad 20 lat doświadczenia, korzystne ceny), ogólnym przeglądem usług, wysuwanymi zakładkami, galerią oraz sekcją opinii Google.
* `oferta.html` – Specjalistyczny opis usług (skrzynie automatyczne, dynamiczna wymiana oleju ASB, sprzęgła suche i mokre, mechanika pojazdowa).
* `kontakt.html` – Dane kontaktowe (tel. 504 045 887, 85 745 59 50), godziny otwarcia oraz mapa lokalizacji ul. Tęczowa 2 w Białymstoku.
* `style.css` – Arkusz stylów z nowoczesnymi animacjami (CSS keyframes, przejścia hover, scroll reveal, wysuwane menu oraz rozwijane zakładki).
* `img/` – Zdjęcia warsztatu (`budynek.jpg`, `warsztat.jpg`, `parking.jpg`) oraz grafika techniczna skrzyni biegów (`skrzynia.jpg`).
