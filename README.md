# Zakład Mechaniki Pojazdowej – Tadeusz Sielawa (Białystok)

Strona internetowa warsztatu samochodowego **Zakład Mechaniki Pojazdowej Tadeusz Sielawa** zlokalizowanego w Białymstoku przy **ul. Tęczowej 2 (15-365 Białystok)**. Warsztat działa od **ponad 20 lat**, zapewnia kompleksową naprawę samochodów, bezpieczne miejsce na placu oraz profesjonalną obsługę, ze szczególnym uwzględnieniem naprawy i konserwacji samochodów z **automatyczną skrzynią biegów** (DSG, tiptronic, S-tronic, MPS6), **dynamicznej wymiany oleju** w ASB, **wymiany sprzęgieł suchych i mokrych** oraz innych usług (wymiana sprzęgieł, rozrządów, naprawa hamulców, zawieszenia, skrzyń manualnych).

## Jak uaktywnić (uruchomić) stronę na GitHub Pages?
1. Wejdź w repozytorium na **github.com** i upewnij się, że w głównym katalogu znajdują się pliki `index.html`, `oferta.html`, `kontakt.html`, `style.css`, `README.md` oraz folder `img/`.
2. Kliknij zakładkę **Settings** na górnym pasku repozytorium.
3. W menu po lewej stronie wybierz **Pages**.
4. W sekcji **Build and deployment → Branch** wybierz gałąź **main** oraz folder **/ (root)**, a następnie kliknij **Save**.
5. Odczekaj około 1–2 minuty, aż GitHub zbuduje i opublikuje witrynę (postęp widać w zakładce **Actions** lub w sekcji **Deployments** na stronie głównej repozytorium).
6. Otwórz link do strony w przeglądarce (w razie potrzeby odśwież stronę skrótem **Ctrl + F5**).
