# Projekt: Zakład Mechaniki Pojazdowej Tadeusz Sielawa (Auto-Serwis)

### Autor: Kacper Kopaczewski
**Przedmiot:** Technologie Internetowe  
**Technologie:** HTML5, CSS3

## Opis projektu
Strona internetowa **Zakładu Mechaniki Pojazdowej Tadeusz Sielawa** zlokalizowanego w Białymstoku przy ul. Tęczowej 2. Witryna prezentuje ofertę naprawy automatycznych skrzyń biegów (DSG, tiptronic, S-tronic, MPS6), dynamicznej wymiany oleju ASB oraz mechaniki pojazdowej.

## Struktura plików:
* `index.html` – Strona główna z prezentacją specjalizacji i galerią warsztatu.
* `oferta.html` – Szczegółowy zakres usług (ASB oraz mechanika ogólna).
* `kontakt.html` – Dane teleadresowe, godziny otwarcia oraz mapa dojazdu (ul. Tęczowa 2, Białystok).
* `style.css` – Nowoczesny, responsywny arkusz stylów.
* `img/` – Wyretuszowane zdjęcia warsztatu (`budynek.jpg`, `warsztat.jpg`, `parking.jpg`) oraz grafika techniczna (`skrzynia.jpg`).
